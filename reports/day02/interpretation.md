# Day 2: Cleveland development-cohort EDA

## Scope and verification
The analysis uses the 242 development records in the frozen Day 1 split. The
61-record internal test remains locked. The source SHA-256 matches the Day 1
manifest. `ca` is excluded from all primary predictor summaries. The outcome is
existing angiographic coronary artery disease (CAD), coded as `num > 0`.

Lucas's local script returned exit code 0. His uploaded continuous and categorical
tables and boxplots were reviewed. The committed script adds outcome validation,
readable plot labels, a reproducible SVG, and a run manifest. Its independent
reference run reproduces both uploaded CSVs numerically. No models were fitted.

## Cohort and missingness
- CAD absent: 131/242 (54.1%); CAD present: 111/242 (45.9%).
- `thal` has two missing measurements (0.83%); all other primary predictors are
  complete in development. `thal` denotes a diagnostic test result.
- This class balance does not warrant automatic oversampling. Compare class
  weighting during development validation if justified by the decision objective.

## Three descriptive observations
1. Maximum achieved heart rate (`thalach`) is lower in CAD-positive patients:
   median 142 beats/min (IQR 123.5–157), versus 160 (144.5–172) in CAD-negative
   patients. The groups overlap substantially.
2. Exercise-related ST depression (`oldpeak`, source scale) is higher in
   CAD-positive patients: median 1.4 (IQR 0.6–2.55), versus 0.4 (0–1.15).
   This is a descriptive contrast, not evidence of independent predictive value.
3. CAD prevalence is higher among patients with exercise-induced angina:
   58/76 (76.3%), versus 53/166 (31.9%) among those without it. These are
   within-category disease fractions, not sensitivity or specificity.

## Two principal limitations
1. These are unadjusted associations in a small historical referral cohort.
   Confounding, selection, and overlapping distributions prevent causal claims
   and do not establish model performance or applicability to modern populations.
2. Sparse categories make estimates unstable: `restecg = 1` includes only three
   patients. Diagnostic-workup features require tests and cannot automatically
   be assumed available at initial presentation.

## Preprocessing decisions for Day 3
Retain extreme observations unless a documented measurement or coding error is
confirmed; boxplot outliers alone do not justify deletion. Treat nominal numeric
codes as categories. Fit imputation and encoding within training folds. Never
fit preprocessing or choose predictors using the locked test. Keep the future-risk
objective separate: these data do not supply prospective outcome labels.

## Reproduce
From the repository root, place the unchanged processed Cleveland input in
`data/raw`, install `requirements.txt`, and run `python scripts/day02_eda.py`.
CSV summaries, PNG/SVG boxplots, and a reference-run manifest are generated in
this directory. The SVG is committed; the PNG can be regenerated by the same
command. The run manifest describes the reference environment, not Lucas's
Windows environment. His complete local `environment.txt` remains unavailable;
this is a follow-up reproducibility item, not a blocker for this reviewed gate.
